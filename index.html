PNH EFOOTBALL - Chi Tiet Du An
Y tuong & Muc tieu

PNH EFOOTBALL sinh ra tu nhu cau thuc te: cong dong game bong da (eFootball, FIFA) nguoi Viet Nam thuong to chuc giai dau nhom ban be nhung khong co cong cu quan ly chuyen nghiep. Toi quyet dinh tu xay dung mot web app hoan chinh de giai quyet van de nay.

Muc tieu: Tao mot nen tang ma nguoi choi co the de dang tao giai, moi nguoi tham gia, theo doi ket qua va bang xep hang theo thoi gian thuc tren ca may tinh lan dien thoai.

Kien truc He thong
Frontend
React + Tailwind CSS. Giao dien SPA responsive, component-based, state management voi Context API.
Backend
Node.js + Express. REST API, JWT Authentication, middleware bao mat, phan quyen theo role.
Database
MySQL. Schema toi uu voi cac bang: Users, Tournaments, Teams, Matches, Results, Standings.
Deploy
Chay local/VPS. Nginx reverse proxy, PM2 process manager, HTTPS SSL.
Chuc nang chinh
Dang ky / Dang nhap / JWT Auth

Thong ke & phan tich du lieu
Nhung gi toi da hoc qua du an

Day la du an pha vo gioi han cua toi. Tu viec chi biet HTML/CSS co ban, toi phai tu hoc Node.js, REST API design, JWT, React hooks, database normalization va nhieu thu nua chi de hoan thanh no. Kho khan lon nhat la thiet ke logic chia bang, tinh toan bang xep hang va dam bao data consistency.

Kho Khan & Giai Phap
  • Logic tinh bang xep hang phuc tap
    Giai quyet bang cach viet stored procedure tinh toan diem, hieu so va head-to-head trong MySQL, dam bao chinh xac du lieu khi nhap ket qua.
  • Phan quyen nhieu cap (Admin/Manager/User)
    Thiet ke role-based access control voi JWT claims, middleware kiem tra quyen o moi API endpoint mot cach ro rang.
  • Responsive tren dien thoai
    Su dung Tailwind CSS voi mobile-first approach, test tren nhieu kich thuoc man hinh thuc te de dam bao trai nghiem tot nhat.
